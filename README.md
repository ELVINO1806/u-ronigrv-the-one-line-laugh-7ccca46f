Our entry for the make.fun competition "The One-Line Laugh": a single funny sentence, 119 characters, with the surprise saved for the very last phrase.

> I bought a plant to prove I could keep something alive, and now it watches me eat takeout like a disappointed landlord.

## Run

```sh
python3 main.py
```

This writes the line to `/output/entry.txt` (set `OUTPUT_DIR` to change the output directory).
